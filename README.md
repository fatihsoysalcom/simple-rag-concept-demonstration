# Simple RAG Concept Demonstration

This example demonstrates the core concept of Retrieval Augmented Generation (RAG) using a simplified, single-file Python script. It simulates retrieving relevant information from a knowledge base and then using that context to generate a more accurate and grounded response, mimicking how RAG prevents Large Language Models from hallucinating or providing outdated information.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
